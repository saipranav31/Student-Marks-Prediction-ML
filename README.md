# Student Marks Prediction using Machine Learning

This project demonstrates a simple **Supervised Machine Learning** model using **Linear Regression**.

## 📌 Project Overview
The model predicts student marks based on the number of hours studied using a labeled dataset.

## 🧠 Algorithm Used
- Linear Regression
- Supervised Learning

## 📂 Dataset
- student_marks.csv  
- Columns:
  - Hours (Independent Variable)
  - Marks (Dependent Variable)

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## ▶ How to Run
```bash
pip install -r requirements.txt
python student_prediction.py
